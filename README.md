# Pobratymy

Monorepo for the `pobratymy.com` rebuild.

## Apps

- `apps/web`: public TanStack Start site deployed to Cloudflare Workers.
- `apps/studio`: Sanity Studio source deployed to Sanity-hosted Studio.

## Commands

```bash
pnpm install
pnpm dev
pnpm dev:studio
pnpm check
```

See `PROJECT_PLAN.md` for product and architecture decisions, and `SETUP.md` for account-bound setup steps.
